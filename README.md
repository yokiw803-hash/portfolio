## 💻 Running the Portfolio Locally

Run with zero dependencies using Node:

```bash
node server.js
```

Or with npm:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser. (If port 3000 is ever occupied, the server automatically switches to the next free port).
